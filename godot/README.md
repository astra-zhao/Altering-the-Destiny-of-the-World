# 《改命：天下》v0.2 M2 · Godot 工程

策略回合、简战、四条可静音 BGM、S1–S3 的 3D 剧情写回、结局与本地存档。用 **Godot 4.6.3** 打开，在 macOS（Apple Silicon / M4）上按 F5 运行。

`web/` 里的文字灰盒已归档，不再作为产品形态。

## 在 Mac mini M4 上打开

1. 安装 **Godot 4.6.3-stable** 标准版（GDScript，不要下带 .NET / C# 的版本）。
   - 版本页：<https://godotengine.org/download/archive/4.6.3-stable/>
   - macOS Universal（含 Apple Silicon）：<https://github.com/godotengine/godot/releases/download/4.6.3-stable/Godot_v4.6.3-stable_macos.universal.zip>
2. 解压后把 `Godot.app` 放进「应用程序」。若系统提示无法验证开发者：在 Finder 里对 Godot **右键 → 打开**，或到「系统设置 → 隐私与安全性」里允许。
3. 启动 Godot，选 **Import**，指向本目录的 `project.godot`。
4. 项目设置里 `config/features` 含 `4.6` 与 `Forward Plus`，应用名是「改命：天下」，主场景是 `scenes/big_map.tscn`。
5. 按 **F5** 运行。右上角应能听到低音地图循环。简战是鼓点，剧情是高音，结算是更慢的收束。标题栏「音量」是主音量，默认约 80%（播放器再低 4 dB），听得清但不顶满；拉到最左接近无声。按「静音」后四条都没有声音，再按「取消静音」按当前音量恢复。进简战、S1–S3 和结算时曲目会换，播放器不停。

首次打开会在本地生成 `godot/.godot/`，已写入仓库 `.gitignore`。

界面中文用内嵌的文泉驿微米黑子集（`theme/WenQuanYiMicroHei-Subset.ttf`，Apache-2.0）。

## M1 怎么试

开局是第 1 回合。局面初值：银两 40、粮草 45、民心 35、辽东稳固 40、后金压力 50、世界线 0、袁崇焕「前线可用」、结交袁「否」。

城上的数字是兵力。袁部一开始在宁远。

1. **行军**：点一座明军城，按「行军」，再点相邻明军城。留 1 守军，其余移走。耗粮 3；大同—宁远是远邻，耗粮 6。粮不够则这一步不成立。
2. **攻城**：点明军城，按「攻城」，再点相邻敌城。弹出简战，约 1 秒后出结果，可「跳过演出」。简战页第一行是「曲：战鼓」，这时 BGM 切到鼓点；按「返回大地图」后回到地图低音。
   - 出兵 = 兵力 − 1。守方强度 = 守军 × 地形（京师 1.10、大同 1.15、宁远 1.20、沈阳 1.10，保定和锦州 1.00）。
   - 攻方城上有袁部，且袁崇焕是「前线可用」：攻方 ×1.25。
   - 攻方强度 ≥ 守方 ×1.12 → **胜占城**；≤ 守方 ×0.88 → **负退回**；否则 **平两损**。
   - 开局从宁远攻锦州会占城（18 兵对 10 兵，又有袁部）。
3. **固守**：选中的明军城本回合防御 ×1.3，不移动。后金若来攻，吃到这个加成。
4. **内政**（可「跳过」）：征粮 = 粮 +8、民心 −4；发帑 = 银 −6、民心 +6；练兵 = 银 −5、粮 −4、选中明军城兵力 +4。银粮不够则不扣。
5. **结束回合**：必须先有主行动。然后后金行动，回合 +1，上限 10。
   - 后金压力 ≥60：从邻城打锦州，锦州已在后金手里就打宁远。
   - 否则看「回合 + 后金压力」：偶数则沈阳兵力 +4，奇数按兵不动。开局压力 50，第 1 回合结束是按兵。
6. **登基夜**：第 1 回合结束后进入。这是一幕低模 3D 夜殿（柱、座、月色和殿内暖光）。镜头从殿门推到御座前，推完才出现 A/B/C。BGM 换成较高的剧情轨。三选一后回到地图，面板数字变掉：
   - A 先稳朝堂：银两 +5，世界线 +5
   - B 先重辽东、点名袁崇焕：辽东稳固 +8，银两 −5，结交袁变为「是」，世界线 +10
   - C 先安民：民心 +10，粮草 −5，世界线 +5
7. 打满第 10 回合，或打完 S3 后再结束一回合，会进入结局结算。

## M2 怎么试

局面面板多了「勤王」。地图上有「存档 / 读档 / 新局」。剧情场景里不能手动存；进入 S1/S2/S3 之前会自动存一笔，中途退出再读档，回到进剧情前的那一回合。

### 触发

- **S2** 在进入第 4、5、6 回合时出现，满足其一即可：曾经由明军控制过宁远（开局算）、辽东稳固 ≤35、或第 6 回合的边报（前两项都不成立时）。镜头从朝堂推到法场再回到抉择，也可按「看朝堂 / 看法场」。
- **S3** 在 S2 已写回之后出现：进入第 8 回合，或京师易手、或保定被后金占了。城头夜景，远处三处烽火，镜头推近后才给选项。
- S3 写回后回到地图，还可以再打 **1** 个策略回合。这个回合结束就结算，不再往后排。第 10 回合结束若还没结算，按同一套优先级强制结算。

### S2 写回（相对按下按钮之前）

| 选项 | 结果 |
| --- | --- |
| A 处死 | 袁=已死，辽东 −20，后金压力 +15，世界线 +5。简战不再有袁部 ×1.25 |
| B 下狱 | 袁=闲置，辽东 −8，世界线 +15。无前线加成 |
| C 复辽职 | 袁=前线可用（站到宁远或另一座明军城），辽东 +12，银 −10，民心 −5，世界线 +30。加成恢复 |
| D 调京营 | 仅当结交袁=是。袁=京营，辽东 +4，世界线 +20。人在京师也不给前线 ×1.25。未结交时按钮是灰的，硬调会失败且不改数 |

### S3 写回

| 选项 | 结果 |
| --- | --- |
| A 倾国勤王 | 辽东 ≥55 且后金压力 ≤45：勤王=成功，压力 −8，世界线 +5。否则勤王=否，世界线 +2，民心 −3 |
| B 固守以拖待变 | 民心 +6，辽东 +3，世界线 +4 |
| C 开海税 | 银 +20，民心 −8，世界线 +10 |

简战也会动前线数字（和剧情写回分开算）：玩家胜占后金城，压力 −8，宁远或锦州再辽东 +4；负则压力 +6、辽东 −3；平则压力 +2。后金占明城，压力 +8，宁远或锦州再辽东 −6。

### 结局（只出一条，甲 > 乙 > 丁 > 丙）

- **甲 中兴微光**：袁不是已死，辽东 ≥60，后金压力 ≤40，世界线 ≥35，京师仍是明
- **乙 残局续命**：不是甲；京师仍是明，且辽东 ≥40 或民心 ≥45
- **丁 另途崩解**：不是甲也不是乙；民心 ≤15 或银两 ≤0（民变就看民心这条）
- **丙 史实沉响**：其余情况，包括袁已死且辽东 <40

结算页有世界线条、三条「你改写了什么」，并切到结局曲。

**改命向（冲甲）**：第 1 回合宁远攻下锦州 → 结束回合，登基夜选 B → 固守度过第 2、3 回合 → S2 选 C → 再固守到 S3 → 选 A。此时压力已由占锦州和勤王卸到 40 以下，辽东过 60，世界线过 35。S3 之后再结束一回合，应是甲。

**史实向（落丙）**：登基夜选 A（不要选 C，免得民心到 45 变成乙）→ S2 选 A → S3 选 B 或 C。袁已死且辽东低于 40，又够不到乙和丁，就是丙。中途不要发帑：发帑民心 +6，再吃 S3 B 的 +6，会到 45，按优先级升成乙。

**崩解向（落丁）**：登基夜选 A，S2 选 A，之后只征粮把民心打到 15 或更低。S3 不要选 B（B 会把民心加回去）。选 C，或选注定失败的 A。结算应是丁，而不是丙。

### 存档

档在本机 `user://campaign_m2.json`（macOS 上一般在 `~/Library/Application Support/Godot/app_userdata/改命：天下/`）。存回合、银粮民心、辽东/压力/世界线、袁状态与所在城、结交袁、勤王、三场剧情是否看过、六城归属和兵力。

1. 地图上按「存档」。
2. 按「新局」，面板回到初值，结交袁和勤王都是否。
3. 按「读档」，数字和城池回到存档那一笔。
4. 剧情里没有存档按钮。杀进程后再读，回到进剧情前自动存的那一笔，不会坏档。

## 在 M4 上导出试玩包（约两分钟）

仓库里有 `export_presets.cfg`，预设名是 **macOS**，架构 **universal**（官方 4.6.3 模板是 universal，含 arm64，M4 能直接开），不签名。

1. 用 Godot 4.6.3 打开本工程。若提示缺导出模板：编辑器菜单 **Editor → Manage Export Templates**，下载 4.6.3 官方模板。
2. **Project → Export**，选 macOS，Export Project。
3. 得到的 `.app` 未签名。第一次打开：Finder 里对它 **右键 → 打开**。双击应进大地图。

命令行（本机已装好 4.6.3 模板时）：

```bash
cd godot
./export_macos.sh
```

脚本会把包打到 `godot/build/macos/改命天下.app`（已 gitignore）。官方 4.6.3 模板里的 macOS 二进制是 universal，预设因此选 universal，而不是单独的 arm64 文件名。导出前工程已打开 **Import ETC2 ASTC**，否则 arm64/universal 会拒导。

## BGM 无头自检

地图、简战、剧情 S1、S2、S3、结算各查一次当前曲目的播放器，必须同时满足：

- `playing` 为真（四条播放器都保持在播，只是音量交叉淡化，切场景不会停）
- 当前曲目 `volume_db > -60`
- `AudioStreamWAV.data` 非空，并且里面有非零采样
- 播放类型是 **Stream**。强制 Sample 时，macOS CoreAudio 和 Dummy 都只会打出 `driver doesn't support sample playback`，声音被丢掉，但 `playing` 仍可能是真
- 向前循环（`loop_end` 大于 `loop_begin`）
- 默认未静音，主音量高于 -60 dB；静音开关能关掉 BGM 总线再打开，且不把播放器停掉

```bash
cd godot
godot --headless --path . -s res://scripts/bgm_check.gd
```

用 **Godot 4.6.3**。成功时标准输出有一行 `BGM_CHECK_OK`，进程退出码是 0。失败会打印 `BGM_CHECK_FAIL` 并以非 0 退出。

无头用的是 Dummy 驱动，听不见声音；这项检查的是播放器状态。编辑器 F5 和导出的 macOS `.app` 走 CoreAudio 混音，Stream 才会从喇叭出来。简战没有单独场景，自检停在大地图上切到 `battle`，和简战浮层是同一条 `Bgm.set_mode("battle")`。
