# 《改命：天下》v0.4 · Godot 工程

策略回合、简战、四条可替换 BGM、S1–S3、结局与本地存档。规则仍是 v0.3：三步引导、常驻的「下一步」、点自己的城再点目标、三张内政大卡、灰按钮说明原因，以及「帮我选」。v0.4 把画面换成 Alice 的 UI v1.2 切图。用 **Godot 4.6.3** 打开，按 F5 运行。

`web/` 里的文字灰盒已归档，不再作为产品形态。

## 在本机打开

1. 安装 **Godot 4.6.3-stable** 标准版（GDScript，不要下带 .NET / C# 的版本）。
   - 版本页：<https://godotengine.org/download/archive/4.6.3-stable/>
   - macOS Universal：<https://github.com/godotengine/godot/releases/download/4.6.3-stable/Godot_v4.6.3-stable_macos.universal.zip>
2. 启动 Godot，选 **Import**，指向本目录的 `project.godot`。
3. 主场景是 `scenes/big_map.tscn`。按 **F5**。窗口 1280×720，最小约 1100×680。

第一次会生成 `godot/.godot/`，已写入仓库 `.gitignore`。

界面文字用切图包里的 Noto Serif SC Bold、Noto Sans SC Regular / Bold（`assets/ui/`，959 字子集，含全部可打印 ASCII U+0020–U+007E 和半角 `=`，SIL OFL 1.1，见同目录 `OFL.txt`）。主题 `theme/main_theme.tres` 指向同一份 Noto Sans。Godot 只引用三份 `.otf`（`scripts/ui_kit.gd` 和主题）。同名 `.woff2` 留在仓库里给 H5，`web/` 仍用系统字体族名，没有引用这些文件。macOS 导出预设排除 `*.woff2`，包里只有 otf。地图、城印、卡片、印章都是 `assets/ui/` 里的切图，文字是字体节点叠在图上。

## 怎么玩

开局是第 1 回合。银两 40、粮草 45、民心 35、辽东稳固 40、后金压力 50、世界线 0。袁崇焕「前线可用」，人在宁远。城上的数字是兵力。

顶上是资源筹码、回合、存档/读档/新局/署名、音量和静音。音量默认约 80%（播放器再低 4 dB）。拉到最左接近无声。静音关的是 BGM 总线，播放器不停。

筹码下面一条是「下一步该做什么」，第二行是刚才那一步的结果。

1. **点城**。先点金色的我方城（京师、保定、大同、宁远）。再点相邻的城：对方的城自动攻城，我方的城自动行军。同一座城再点一次，只提示「还是这座城」，局面不变。不相邻，只提示走不过去，局面不变。点对方的城当起点，会请你先点自己的城。城名和兵力是字，不是烤在印章上的。
2. **主行动印章**。选中我方城之后，城下方出现行军、攻城、固守三枚印章，下面是朱红名牌。想指定方式就先点其中一个，再点目标。固守立刻生效。灰色印章旁边写着为什么不能按。
3. **内政**。右边三张大卡：征粮、发帑、练兵。数字仍是原来的规则（见下表）。每回合内政最多一次。没有单独的「跳过内政」按钮；主行动做完后，直接点「下一回合」就会把没做的内政跳过。练兵没选中我方城时是灰的，卡里写「请先选中己方城池」。
4. **下一回合**。右下角朱砂印。主行动还没做时它是灰的，原因写在印上面。战斗浮层开着、或正在进剧情时，不能推进回合。短时间里连点两下，只会过一个回合。
5. **帮我选**。地图左下角常开。弹出 2 到 3 条，每条有理由。点一条才执行；只打开清单不会扣粮、不会出兵。连点这个钮也不会重复扣。剧情 S1/S2/S3 的选项不由它决定，面板会写「请你自己选」。主行动已经用过时，它只推荐「下一回合」。收起后面左下角留一枚「帮我选」按钮。
6. **取消**。Esc，或点地图空白处。
7. **存档 / 读档 / 新局 / 署名**。在顶栏资源筹码和音量之间。剧情场景里不能手动存；进入 S1/S2/S3 之前会自动存一笔。

### 第一次的引导

编号气泡按顺序指三处，旁边一句人话：先点亮着的城，再选一个行动，最后点「下一回合」。点「跳过引导」，或三步都走完，这一局不再出现。同时会在本机写下 `user://v03_guide.json`（`{"dismissed": true}`）。以后开新局也不再出现。没点过城，直接在「帮我选」里固守、行军或攻城，也算走完前两步，气泡进到「下一回合」。

读档先按存档里的引导进度恢复。磁盘标记若是合法的 `{"dismissed": true}`，这次读档不会把已经跳过或走完的引导再叫出来。标记不在，或文件坏了（不是合法 JSON），就不当作已跳过：新局重新出现引导，中途存档仍回到当时那一步。

## 验收

下面命令里的 `godot` 换成你本机的 Godot 4.6.3 可执行文件。

### 无头：规则和播放器

```bash
cd godot
godot --headless --path . -s res://scripts/advisor_check.gd
godot --headless --path . -s res://scripts/advisor_smoke.gd
godot --headless --path . -s res://scripts/bgm_check.gd
```

成功时分别打印 `ADVISOR_CHECK_OK`、`ADVISOR_SMOKE_OK`、`BGM_CHECK_OK`，退出码 0。

`advisor_smoke` 只负责一直点推荐清单里的第一条，直到结局。剧情选项是脚本在扮玩家：S1 选 B、S2 选 C、S3 选 A。推荐引擎不会替玩家写回这三幕。这条路应走到结局甲。

`bgm_check` 在无头模式下音频驱动是 **Dummy**。它能证明四条播放器在播、当前曲音量高于 -60 dB、流是可循环的 OGG、播放类型是 Stream、默认主音量听得见、静音开关能关开 BGM 总线。它**听不见声音，不能当成喇叭里真的有声的证据**。这条和 v0.3 相同，不因换了界面而改变。

### 对照 UI v1.2 设计稿

设计稿是三屏：大地图、简战（交战中 / 胜 / 负 / 平）、结局。切图清单在 `assets/ui/README-切图清单.md`。验收时看这些，不看设计稿里的示意战力。

- 分辨率 1280×720。底图分别是 `bg_map_liaodong`、`bg_battle_banners`、`bg_ending_night` 加 `ending_scroll`。
- 文字都是字体节点。标题用 Noto Serif Bold，正文用 Noto Sans。城名、兵力、「下一回合」、卡片文案都不烤在图里。胜负平三枚 `stamp_*` 本身带字，这是唯一例外。
- 九宫格边距按切图清单：小面板 10、中面板 20、大面板 26、帮我选 20、内政卡 20、筹码 10、推荐行 6、名牌 8、数据砖 6、进度条左右 6 上下 0。
- 按钮、内政卡、城印用切图的 normal / hover / pressed / disabled / selected。城印切图只有 normal / hover / selected，按下时用 selected。城池始终可点，没有 disabled 图。灰态旁边或卡内有一句原因。
- 邻接是实线。大同—宁远是 `campaign_baseline` 里的远邻，画虚线并标「远邻」。
- 简战交战中有进度条和「跳过演出」。胜、负、平只有「返回大地图」。攻方大数字是守军兵力（出兵 + 1），旁边写「出兵 N」。有效兵力用游戏规则，不是设计稿上的「兵力 × 系数」。开局宁远 18 打锦州 10、有袁部：出兵 17，攻方有效 21.25，守方有效 10.0，结果是胜并占城。设计稿上的 22.5 是示意，不要拿来对数字。
- 结局卷轴有世界线（按 40 封顶的比例画朱砂条）、改写记、2×3 数据砖。页脚只写真实署名：`配乐：Floating Lanterns · John Bartmann · CC0`。
- 无头自检仍是上面三条，不看画面。出图脚本 `scenes/qa_ui_capture.tscn` 只给对照截图，不进正式游玩。

### 真声卡

必须在有真实音频驱动的机器上跑，**不要加 `--headless`**。加了就会落到 Dummy，峰值没有意义。

```bash
cd godot
godot --path . -s res://scripts/qa_audio_real.gd
```

通过的标准：驱动不是 Dummy；地图、简战、剧情、结算这些听得见的场景 `peak_db > -60`；音量滑条打到 0 时 `peak_db < -80`；日志里没有 sample playback 警告。

这台云环境的驱动是 Dummy，所以这里不能把这条判成通过。脚本按上面的路径放好，到有声卡的机器上跑。

### 改命向（冲甲，三分钟内能走完第 1 回合）

第 1 回合点宁远，再点锦州（或「帮我选」里的攻城），等简战出「胜占城」，点「返回大地图」，再点「下一回合」。登基夜选 B。之后固守度过第 2、3 回合。S2 选 C。再固守到 S3，选 A。S3 之后再结束一回合，应是甲。

甲 > 乙 > 丁 > 丙。粮草低于 3 时，「帮我选」不会推荐出兵（行军或攻城），第一条是征粮，理由里写粮草。只剩一座我方城时不推荐行军。不会推荐算下来会输的攻城。

## 曲目

四条都在 `audio/tracks/`，文件名就是轨名。换曲子只覆盖同名文件。导入用 Godot 4.6.3 的 `oggvorbisstr`，**Loop 打开**，`loop_offset=0`。运行时再把 `loop` 设上，播放类型是 **Stream**。缺文件时才退回一段很短的程序音，并在控制台警告。

### Floating Lanterns 为什么留下

源文件是 96,016 bps、44.1 kHz 立体声 MP3，峰值 −0.35 dBFS，RMS −17.7 dBFS，没有削波。有声段落的频谱质心约 203 Hz，95% 能量在 699 Hz 以下，99% 在 1,180 Hz 以下，99.9% 在 2,331 Hz 以下。频段 RMS：0–200 Hz −19.3 dB，200 Hz–2 kHz −22.4 dB，2–5 kHz −44.8 dB，5–8 kHz −66.9 dB，8 kHz 以上低于 −77 dB，16 kHz 以上是 MP3 低通后的底噪（约 −110 dB）。这是一首低音乐曲加上 96 kbps 的带宽上限，不是破损文件。

备选 Oriental Somber（OGA，CC0）是 16 kHz、大约 39 kbps 的 Vorbis，奈奎斯特频率只有 8 kHz，峰值 −17.7 dBFS、RMS −36 dBFS，尾部还有很长的静音，乐器是日本筝、三味线和尺八。带宽更窄，也不贴这一局的场景，所以没有替换。

BiteMe 的页面还写了 “You cannot resell this edit.” 这两首只作为游戏里的 BGM，不单独出售。

## 规则（和 v0.2 相同）

### 主行动和内政

1. **行军**：留 1 守军，其余移到相邻我方城。耗粮 3；大同—宁远是远邻，耗粮 6。粮不够则这一步不成立。
2. **攻城**：打相邻敌城。弹出简战，大约 1.2 秒后出结果，可「跳过演出」。这时 BGM 切到简战；「返回大地图」后回到地图曲。
   - 出兵 = 兵力 − 1。守方强度 = 守军 × 地形（京师 1.10、大同 1.15、宁远 1.20、沈阳 1.10，保定和锦州 1.00）。
   - 攻方城上有袁部，且袁崇焕是「前线可用」：攻方 ×1.25。
   - 攻方强度 ≥ 守方 ×1.12 → **胜占城**；≤ 守方 ×0.88 → **负退回**；否则 **平两损**。
   - 开局从宁远攻锦州会占城（18 兵对 10 兵，又有袁部）。
3. **固守**：选中的明军城本回合防御 ×1.3，不移动。
4. **内政**：征粮 = 粮 +8、民心 −4；发帑 = 银 −6、民心 +6；练兵 = 银 −5、粮 −4、选中明军城兵力 +4。银粮不够则不扣。
5. **结束回合**：必须先有主行动。然后后金行动，回合 +1，上限 10。
   - 后金压力 ≥60：从邻城打锦州，锦州已在后金手里就打宁远。
   - 否则看「回合 + 后金压力」：偶数则沈阳兵力 +4，奇数按兵不动。开局压力 50，第 1 回合结束是按兵。
6. **登基夜**：第 1 回合结束后进入。低模 3D 夜殿，镜头从殿门推到御座前，推完才出现 A/B/C。BGM 换成剧情轨。
   - A 先稳朝堂：银两 +5，世界线 +5
   - B 先重辽东、点名袁崇焕：辽东稳固 +8，银两 −5，结交袁变为「是」，世界线 +10
   - C 先安民：民心 +10，粮草 −5，世界线 +5

### S2 / S3

- **S2** 在进入第 4、5、6 回合时出现，满足其一即可：曾经由明军控制过宁远（开局算）、辽东稳固 ≤35、或第 6 回合的边报。
- **S3** 在 S2 已写回之后出现：进入第 8 回合，或京师易手、或保定被后金占了。
- S3 写回后回到地图，还可以再打 **1** 个策略回合。这个回合结束就结算。第 10 回合结束若还没结算，按同一套优先级强制结算。

| S2 | 结果 |
| --- | --- |
| A 处死 | 袁=已死，辽东 −20，后金压力 +15，世界线 +5。简战不再有袁部 ×1.25 |
| B 下狱 | 袁=闲置，辽东 −8，世界线 +15。无前线加成 |
| C 复辽职 | 袁=前线可用，辽东 +12，银 −10，民心 −5，世界线 +30 |
| D 调京营 | 仅当结交袁=是。袁=京营，辽东 +4，世界线 +20。未结交时按钮是灰的，并写明原因 |

| S3 | 结果 |
| --- | --- |
| A 倾国勤王 | 辽东 ≥55 且后金压力 ≤45：勤王=成功，压力 −8，世界线 +5。否则勤王=否，世界线 +2，民心 −3 |
| B 固守以拖待变 | 民心 +6，辽东 +3，世界线 +4 |
| C 开海税 | 银 +20，民心 −8，世界线 +10 |

简战也会动前线数字：玩家胜占后金城，压力 −8，宁远或锦州再辽东 +4；负则压力 +6、辽东 −3；平则压力 +2。后金占明城，压力 +8，宁远或锦州再辽东 −6。

### 结局（只出一条，甲 > 乙 > 丁 > 丙）

- **甲 中兴微光**：袁不是已死，辽东 ≥60，后金压力 ≤40，世界线 ≥35，京师仍是明
- **乙 残局续命**：不是甲；京师仍是明，且辽东 ≥40 或民心 ≥45
- **丁 另途崩解**：不是甲也不是乙；民心 ≤15 或银两 ≤0
- **丙 史实沉响**：其余情况，包括袁已死且辽东 <40

**史实向（落丙）**：登基夜选 A（不要选 C，免得民心到 45 变成乙）→ S2 选 A → S3 选 B 或 C。中途不要发帑。

**崩解向（落丁）**：登基夜选 A，S2 选 A，之后只征粮把民心打到 15 或更低。S3 不要选 B。

## 存档

档在本机 `user://campaign_m2.json`（macOS 上一般在 `~/Library/Application Support/Godot/app_userdata/改命：天下/`）。版本 3 多了引导进度。旧的版本 2 存档仍能读；里面没有引导字段时，不改当前的引导状态。

读档会先整份检查，再改内存里的局面。半截文件、缺字段、城池不是六座、势力不是「明」或「后金」、数字不是数，都返回失败，**不改当前局面**，地图上写「存档不完整，已保持当前局面。」

音量和静音在 `user://audio_prefs.json`。

## 在 M4 上导出试玩包

仓库里有 `export_presets.cfg`，预设名是 **macOS**，架构 **universal**，不签名。

1. 用 Godot 4.6.3 打开本工程。若提示缺导出模板：编辑器菜单 **Editor → Manage Export Templates**，下载 4.6.3 官方模板。
2. **Project → Export**，选 macOS，Export Project。
3. 得到的 `.app` 未签名。第一次打开：Finder 里对它 **右键 → 打开**。

```bash
cd godot
./export_macos.sh
```

脚本会把包打到 `godot/build/macos/改命天下.app`（已 gitignore）。
